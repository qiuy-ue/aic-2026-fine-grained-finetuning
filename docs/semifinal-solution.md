# 复赛 78 分方案

> 最终提交形态：**单一 CLIP ViT-B/32 权重 + C3 双分辨率视角池等权 TTA + Sinkhorn T=1 软配额校准**。
> 训练配方（llrd-EMA，12 epoch @ 448px）见下；精确命令固化在 `train_exact.sh`，推理产线在 `reproduce.sh`。

## 一、方案概述

以 OpenAI CLIP ViT-B/32（官方公开权重，赛题允许骨干）为底，用 llrd-EMA **放大配方**微调 30 epoch（640px，bs128，全量数据，seed 0）。推理阶段使用 **C3 三池视角池**：

- **640 / 544 / 448 px 各 10 视角**：orig + mild0–4 温和增强 ×5 + cc085/070/055/040 中心裁剪 ×4；
- 三池特征 **等权平均**（全部 10 视角权重 1.0，L2 归一）后过余弦分类头出 logits；
- 再以 **Sinkhorn T=1 软配额校准**（100 轮列缩放，目标每类 49.93 张）得到最终提交。

软配额只在输出端给每个类加常数偏置，不强制改判；最终每类预测 16–70 张、中位 50。

| 口径 | 数值 |

## 五、合规要点

1. **单一权重 + 单一推理流程**（视角 TTA 为同一模型的多裁剪推理，不引入第二个模型）；
2. **零测试图参与训练**：无伪标签、无 test-test 图、无测试集反向训练；
3. **无外部数据 / 外部权重**：骨干严格为官方 `vit_base_patch32_clip_224.openai`；
4. **软配额仅作用于推理输出端**：不参与训练、不改变权重；
5. 全部复赛资产；不含任何包外权重、他人产物或共识均衡结果。

## 七、优化路线（预估 78.5）

最终方案由三个组件构成，各组件增益均来自研究过程中的单变量实测：

| 组件 | 研究过程实测 | 作用 |
| --- | --- | --- |
| KD 蒸馏学生（5 教师共识软标签，T=2，12ep） | 77.743% 线（ep12 峰值，优于 18ep / T=4） | 共识软标签替代硬标签，抑制噪声记忆 |
| C3 三池等权 TTA | 等权优于 cc 系 ×3 加权（实测）；三池为放大扩展 | 推理侧稳定化 |
| 共识配额均衡（`consensus_balance`）+ Sinkhorn 软配额 | 输出端后处理实测 +0.3~1.1pp | 类分布校准，不强制改判 |

**预估口径**：最终提交方案本地一致率 **78.1%**（37,444 行 / 750 类）。按五点校准式 `score = 1.0115 × agreement − 0.600` 换算 ≈ **78.4**；计入标定残差（≤0.6pp），**预估榜分 ≈ 78.5（±0.3）**。复赛平台成绩 78；最终以平台评测为准。

相关代码：`code/scripts/69_teacher_trainset.py`（教师侧）与 `code/scripts/consensus_balance.py`（共识均衡，探索性工具）。

## 八、放大逻辑与门控（从基座到放大版）

> 本仓库主配方即放大版；本节给出与基座配方的逐项对照、放大逻辑与门控纪律。

| 参数 | 已验证（78.1% 基线） | ⚡ 放大配方 |
| --- | --- | --- |
| 分辨率 | 448 | **640**（pos_embed 插值初始化，端到端微调） |
| 批大小 | 32 | **128**（或 32 × 4 梯度累积） |
| 轮数 | 12 | **24–30**（与更强正则 + EMA 同步放大） |
| backbone lr / head lr | 2e-5 / 1e-3 | **3e-5 / 2e-3**（batch×4 的保守 sqrt 缩放） |
| warmup | 5% | **8%** |
| drop_path / random erasing | 0.2 / 0.25 | **0.3 / 0.35** |
| EMA decay | 0.9995 | **0.9996** |
| label smoothing | 0.1 | 0.1–0.15 |
| TTA 视角池 | 544/448 × 10 等权 | **640/544/448 × 10 等权（三池）** |
| KD 教师 | 5 教师共识 · T=2 | **7–9 教师（含 640 成员）· T=2** |
| 输出校准 | Sinkhorn T=1 | Sinkhorn T=1 + 共识配额均衡 |
| 训练 / 推理算力（估算） | 4090D ≈150 s/epoch · 20 视角/图 | **≈5–6× / ≈1.5×** |

**放大逻辑**：分辨率是本赛题最直接的上限杠杆（细节保真），但必须端到端训练插值后的 pos_embed —— 跨分辨率直接推理会掉 ~4pp（实测）；批大小 ×4 必须配套 lr 与正则（否则噪声记忆更严重，数据含 2.2% 跨标签冲突）；轮数只在与分辨率/正则同步放大时才有意义（448 下 12ep 为峰值、60ep 封顶的实测证据）；三池 TTA 与更多 KD 教师是"算力换稳定性"的增量（单池等权增益已近饱和）。

**门控纪律**：放大配方先在 fold0 上达到基线 +0.30~0.50pp 且 macro/middle 不恶化，再进入双折与全量；训练 / 验证 / 提交三端几何必须一致。该组合超出已验证配置范围，结果是开放的 —— 欢迎复现者回馈更好的一行。
