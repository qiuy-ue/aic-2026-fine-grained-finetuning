# 初赛研究工作协议

本文件是本项目后续实验的控制面。代码可以由 LLM 实现，但研究结论必须由负责人根据独立证据确认。

## 负责人负责的判断

- 提出研究假设，并写明预期改变的机制和可证伪条件。
- 判断本地验证是否可信，优先使用严格近重复分组验证。
- 决定实验优先级和停止条件；不因单次最好分数保留模块。
- 区分疑似错标、重复冲突和真实难例，默认降权而不是删除。
- 分析本地与线上差异，先审计分布、预处理和预测先验，再改模型。
- 只有当独立折、不同随机种子或线上单因素结果一致时，才保留模块。

## LLM 负责的可验收实现

- 实现损失函数、样本权重、冲突组软标签和全部配置项。
- 生成错误分析脚本：按类别、分辨率、来源、重复组、置信度和预测熵汇总。
- 汇总 `metrics.jsonl`、OOF、预测分布和线上分数，更新 `logs/experiment_tracker.csv`。
- 自动检查单变量原则：每个 run 必须声明基线、变更字段、验证范围和是否改变推理流程。
- 修复训练、显存、数据读取、预处理、checkpoint 和推理问题，但不得悄悄改变研究变量。
- 整理论文表格、配置快照、环境信息和从训练到提交的复现说明。

## 每个实验的最小契约

每个实验必须有唯一 `run_id`，并保存：

1. 配置快照和代码版本；
2. 训练/验证日志、每折分数和均值方差；
3. OOF 概率、测试概率和预测类别计数；
4. 变更字段列表、基线 run、假设、停止条件；
5. 产物路径和提交状态（若已线上评分）。

禁止把全量 OOF 结果反向用于同一 OOF 的模型选择或权重生成。疑似错标规则必须只依赖训练折可获得的信息，或明确标记为最终全量训练专用。

## 当前证据与下一步

- 已知线上锚点：`clip_b32_final`，Top-1 `0.52`（平台记录 `57`）。
- 已知本地结果：普通五折 OOF `0.731723`，严格参考约 `0.719696`；近重复和测试域分布差异使普通 OOF 不足以单独决策。
- `letterbox + cosine head + 解冻 1 block + SCE + 无 MixUp` 在严格 fold 0 为 `0.653505`；它比历史 MixUp 版本高 `+0.013848`，但尚未在独立折或种子复核。
- 跨标签完全重复图的组分布软标签为 `0.651253`，相对匹配控制 `-0.002252`，不保留。
- 下一项研究实验是复核无 MixUp 锚点（strict fold 1 或独立种子），随后单变量比较解冻最后两层；完整设计见 `ARCHITECTURE_EXPERIMENT_DESIGN.md`。

## 保留模块的门槛

默认门槛是：严格 fold 0 提升至少 `0.5` 个百分点，且不恶化关键类别覆盖；随后在一个独立折或独立种子复核。线上提交一次只改变一个核心因素，并记录预测分布和分数。
