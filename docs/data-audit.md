## 噪声证据与处置原则

- **1,032 组完全相同的图片出现在多个类别目录** —— 约 2.2% 的内生标签冲突密度，是「含噪标签」赛题的实证起点。
- 完全重复组强制同折隔离（阻断字节级泄漏）；感知近重复只做复核候选，不自动删除（链式相似会跨多类合并，破坏折划分）。
- 人工复核只用于理解数据；最终降权 / 软标签 / 筛选规则必须可由代码自动复现（参见 `code/cache/dup_exclude.txt` 等训练侧缓存）。
- 单样本高损失 ≠ 错标。跨标签特征孪生清洗（R2）最终零收益，说明冲突标签是数据内生属性，删 memory 成员只会换一个同样错误的投票方向。

## 关键教训

- tail 桶只有 36 个验证样本，方差过大，不能作为门控依据；有意义的长尾观测桶是 middle（479 样本）与 macro 指标。
