# 鲁棒 CLIP 微调实验设计

## 研究目标

在只能使用 OpenAI CLIP ViT-B/32、训练标签含噪且不能使用外部数据的约束下，寻找能保留 CLIP 视觉先验、降低噪声监督破坏并改善细粒度识别的单模型训练流程。

## 赛题约束带来的设计调整

类别是匿名 ID（`0000` 至 `0499`），没有合规的物种名称或类别描述。因此不能将“图像-类别文本相似度”作为标签正确性的直接证据，也不能把自然语言零样本分类作为可信主基线。本项目将 CLIP 用作允许的视觉预训练骨干，并以冻结视觉教师、增强一致性、训练折内置信度和重复冲突审计替代该分支。

初赛每类训练样本数约为 201 至 213，不是典型长尾集。长尾损失、重采样和 logit adjustment 仅在复赛/半决赛类别不均衡得到审计证据后启用。

## 可信验证面

- 主验证：`input/train_folds_near_cache224.csv` 的严格近重复分组 fold 0。
- 复核：同一设置使用 fold 1 或新随机种子，不能只看一次最佳 epoch。
- 报告：Top-1、Top-5、每类 Macro Accuracy、冲突重复/非冲突样本 Accuracy、预测熵与类别覆盖。
- 线上：每次只提交一个已经通过两次本地验证的核心改动；线上低于 `0.52` 的历史候选不能作为新基线。

## 阶段 A：微调边界和分类头

假设 A：细粒度噪声任务中，弱更新 CLIP 比无约束全量微调更稳定。

固定：224 letterbox、SCE、无 MixUp、6 epoch、相同 seed 和严格折。

| ID | 唯一变量 | 对照 | 保留门槛 |
|---|---|---|---|
| A0 | 仅分类头 | 当前 last-1 block | 只作下界 |
| A1 | 最后 1 block | 当前锚点 | fold 1 或新 seed 复核 |
| A2 | 最后 2 blocks | A1 | 两次验证均提升 >=0.5pp |
| A3 | LoRA/Adapter | A1 | 两次验证均提升 >=0.5pp，显存和推理不劣化 |
| A4 | 全量微调 | A1 | 仅作过拟合诊断；无明确跨验证收益不保留 |

Prompt tuning 和自然语言零样本不进入第一轮。若后续实现，必须定义为可训练视觉/类别查询模块，并与分类头做同成本对照，不能宣称使用了匿名类别的语义文本。

## 阶段 B：鲁棒监督

假设 B：在已固定的微调边界上，鲁棒损失比普通 CE 更不易记忆错误标签。

每次只替换 `loss`：CE、CE+label smoothing、SCE、GCE、bootstrapping。先以当前 SCE 为参照，不同时叠加样本权重或一致性。保留条件为两次严格验证平均提升 >=0.5pp，且非冲突样本准确率不下降超过 0.2pp。

已拒绝：对 2,095 张跨标签完全重复图直接使用组标签分布软标签（`-0.225pp` 对匹配控制）。这不证明它们不是错标，只说明该处理方式不应进入主模型。

## 阶段 C：CLIP 知识保持与一致性

假设 C1：冻结原始 CLIP 视觉教师的特征锚点能限制噪声引起的表征漂移。

`L = L_robust_cls + lambda_feature * (1 - cosine(z_tune, stopgrad(z_ref)))`

候选 `lambda_feature` 为 `0.01, 0.03, 0.1`，先使用最小值。冻结教师必须与允许的 OpenAI CLIP ViT-B/32 相同，不引入额外模型或数据。

假设 C2：弱/强增强的一致性可在不信任标签时稳定预测。

`L = L_robust_cls + lambda_consistency * KL(p_weak || p_strong)`

先验证轻增强（翻转、轻微颜色扰动）；不直接使用激进裁剪、Random Erasing 或多 crop，避免抹除细粒度判别区域。C1 与 C2 分开测试，不能同轮叠加。

## 阶段 D：置信度与课程学习

假设 D：训练折内、时间平滑的置信度加权优于硬删除。

可靠性分数只使用当前训练折中可获得的信息：EMA 预测置信度、两视图一致性和训练损失轨迹。不得把验证折标签或全量 OOF 反向用于该折训练。先离线审计“低权重样本是否集中在冲突组、是否同时包含真实难例”，再训练权重版本。

候选权重：`0.25, 0.5, 1.0` 的连续权重；禁止首轮删除样本。课程学习必须以同一权重函数的固定阶段边界作为唯一变量。

## 阶段 E：蒸馏与长尾

随机初始化教师只在 A-D 已稳定且出现平台期后考虑。教师只能用当前阶段训练数据从头训练，最终推理仅保留 CLIP 学生。蒸馏要先验证教师在严格折上优于学生，否则没有知识可迁移。

长尾模块只针对复赛/半决赛的数据审计启动；报告 Overall、Macro、Head、Medium、Tail Accuracy。初赛不以人为均衡预测配额作为优化手段。

## 推理与线上策略

单模型 hflip TTA 可以保留为独立推理变量，但只能在新训练配置的严格验证中复核。温度、logit bias 或类别配额只可在 OOF 上选择；测试集预测分布异常只能用于诊断，不能替代验证证据。

## 下一轮执行顺序

1. 在 strict fold 1 复核 A1（last-1 block、cosine、SCE、无 MixUp）。
2. 若 A1 稳定，完成 A2（last-2 blocks）单变量对照。
3. 以胜出的 A 配置为固定底座，运行阶段 B 的 CE 与 SCE 小范围对照。
4. 仅在阶段 B 获得稳定基线后，实现并测试 C1 特征保持。
5. 之后才进入 C2、D 和蒸馏。
